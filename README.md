# Customer-Churn-Analysis

Project Overview

Developed an interactive Customer Churn Dashboard using SQL Server and Power BI to identify key factors influencing customer churn and support customer retention strategies.

Tools Used
SQL Server
SQL Server Management Studio (SSMS)
Power BI Desktop
DAX
Microsoft Excel
Key Features
Imported and validated customer data using SQL Server.
Performed SQL analysis to calculate churn rate and identify churn drivers.
Built interactive Power BI dashboards with KPIs and drill-down analysis.
Added slicers for demographic and contract-based filtering.
Dashboard Highlights
Total Customers
Churn Rate
Average Monthly Charges
Average Tenure
Churn by Contract Type
Churn by Internet Service
Churn by Payment Method
Customer Demographics Analysis
Business Insights
Month-to-month contracts showed the highest churn.
Customers with Fiber Optic internet had a higher churn rate.
Customers who churned had higher average monthly charges.
Customers with shorter tenure were more likely to churn.
